How It Works

Four steps to securely share any file with anyone, with no accounts required.

1
📂

Drag and drop your files or click to browse. Supports documents, images, PDFs, and archives up to 100 MB.

2
🔐

3

Security Features

What Protects Your Files

Every feature listed here is actually implemented and enforced on every request.

🔐

Password Protection

Passwords are hashed with bcrypt before storage. Plaintext passwords are never stored or logged anywhere.

📁

Secure File Storage

Files are stored using server-generated UUID filenames — not the original name — preventing path traversal or filename guessing.

🔗

Unique Share Links

Every file gets a cryptographically random UUID share link. Sequential IDs or predictable patterns are never used.

⏳

Temporary File Availability

Files automatically expire after your chosen time window (24 hours to 30 days). Expired files cannot be downloaded.

🛡️

Brute-force Protection

The password verification endpoint is rate-limited to 10 attempts per IP per 15 minutes. Limit exceeded returns HTTP 429.

🚫

File Type Validation

Only safe file types are accepted. Unsupported formats are rejected before storage, and partial uploads are cleaned up.

📊

Download Limits

Optionally limit a file to 1, 5, or 10 downloads. Once the limit is reached, the file is no longer downloadable.

🔑

Private Management Links

You receive a separate management link secured with a 256-bit random token. Only the token holder can view stats or delete the file.

💾

Persistent Storage

File metadata is stored in SQLite — not memory. File records survive server restarts. No lost data on reboot.
